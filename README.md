# Bluestock Mutual Fund Analytics

## Project Overview
This project analyses mutual fund industry data to understand AUM distribution, SIP inflows, category trends, scheme performance, risk metrics, investor transactions and portfolio holdings.

## Project Objectives
- Explore mutual fund industry trends.
- Analyse AUM and SIP inflows.
- Compare scheme performance and risk.
- Study investor transaction patterns.
- Build an interactive analytics dashboard.

# Bluestock Mutual Fund Analytics — Day 3 EDA

## Files
- `notebooks/EDA_Analysis.ipynb`: reproducible analysis covering the 10 requested EDA areas and 18 chart outputs.
- `run_eda.py`: executes the notebook from the repository root.
- `data/processed/`: place the ten cleaned Day 2 CSVs here.
- `outputs/charts/`: PNG charts and interactive Plotly HTML files generated on execution.
- `outputs/eda_findings.md`: ten evidence-led findings generated by the notebook.

## Windows PowerShell setup
```powershell
py -m venv .venv
.\\.venv\\Scripts\\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

Copy all ten CSVs from Day 2 `data/processed/` into this repository's `data/processed/` folder, preserving filenames. Then run `python run_eda.py` or open the notebook and select Run All.

## Data integrity
Day 1's README says the originally supplied NAV CSV has 3,211 rows but only one unique scheme code. The notebook plots only the scheme histories actually present; it does not fabricate 40 histories. AUM, SIP and folio headline values are calculated from the data rather than hard-coded. Plotly PNG export requires Kaleido; HTML versions are also saved.
